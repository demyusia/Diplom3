# Diplom3 Тестирование UI для дипломной работы (задание 3)

Использованы библиотеки: Junit v4.13.2, Selenium-java v4.45.0, Webdrivermanager v6.3.4, Rest-assured v5.5.7, Lombok v1.18.46, Allure v2.15.0, Gson v2.14.0, Javafaker v1.0.2
Работа проводилась для веб-приложения Stellar Burgers https://stellarburgers.education-services.ru/:

Протестирована следующая функциональность:
1.1 Регистрация пользователя
1.2 Вход в аккаунт
1.3 Переходы по разделам конструктора
2 Тестирование проводилось в двух окружениях: Google Chrome и Яндекс Браузере.
3 Сделан Allure-отчёт. Отчёт добавлен в пул-реквест.
